## One starting point, then any route

**Connect and test your Pico is the only prerequisite.** Run the starter on a real Pico before marking it done.

After that, every page is available without completing another page. You can start with components, code, a case, an idea or a test, and move between them freely. Progress ticks are optional records, not gates.

Component pages supply wiring, code and a small test. The rule and joining pages offer optional worked circuits you can adapt. The testing page works with whatever you have so far.

Red/pink boxes contain the Pico setup reminder and wiring cautions. Links to other component pages offer help, not a required sequence.
