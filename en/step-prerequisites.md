## When to go back

**1A is the only compulsory first page.** Run the starter on a real Pico before marking it done. After that, route numbers organise the menu, not the build order.

- **2A–2C:** Sketch or craft whenever you like after 1A. Keep the Pico and USB accessible.
- **3A–3J:** Wire and test one input on its own before relying on it.
- **4A–4D:** Wire and test one warning on its own. Use one buzzer on GP9 at a time.
- **5A–5C:** Follow the linked component tests first. These rules are optional.
- **6A:** Test an input and warning alone, then combine. This makes the first complete alarm.
- **6B:** First make 6A work; add only parts that improve your idea.
- **7A:** Test the complete alarm with someone else; improve one thing at a time.
- **8A–8C:** Optional examples. Borrow any technique without copying the whole design.

A red/pink caution box links to a test you may need. It is a return route, not a locked page.
